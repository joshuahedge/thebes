# Version 9.0 "Dynasty": rulings 1620-1629 (wave 2, the balance check)

The bars are src/data/dynasty.js `TITLES`; the traits `TRAITS` (unchanged here). The new tests are tests/v90/balance/ (`heirs.test.js` T4, T5 and T7, `titles.test.js` T6, `runs.test.js` T1 for the Builder and T3 for the Unconquered). The older runs' drivers take a heir (tests/stage4/balance/capitalRun.js `runCapital`, tests/v50/grand/grandRun.js `runGrand`, tests/v60/balance/dangerRuns.js `lateDangerRun`, `greatDangerRun`, `grandDangerRun`), the Steady by default, so every older run is the run it was. The probe that measured every heir's long runs was a scratch test, never committed; its numbers are below and in the balance check's report.

1620. The balance check owns every balance and frame pin; the suite runs T1 for the Builder and T3 for the Unconquered, and the other heirs' long runs are a reported probe. — Cost if wrong: a heir's long-run drift is caught only by the next balance check.
1621. The Unconquered's bar 3 -> 5 raids beaten (none lost, no tribute). With 3, every balance run past year 6 met it, and the 6-year capital run (3 beaten) did too. At 5 the 20-year dangers runs (13 and 11 beaten) earn it and the capital run does not. — Cost if wrong: a careful defender needs about eight years of raids before the title, not five.
1622. The Builder's bar 2,000 -> 4,600 monument units. With 2,000 every balance run was the Builder (fits 1.8-7.8: the scripted players all build monuments). 4,600 sits where the two named runs part: the great-work run's 13,542 units beat its 13 raids (2.94 against 2.60), while the dangers runs' 10,374 and 9,111 units lose to their 13 and 11 raids (2.26 against 2.60, 1.98 against 2.20); the capital run's 4,067 falls short, so it is the Bountiful. — Cost if wrong: a reign with only a small mastaba and an obelisk (about 3,000 units) is no longer the Builder.
1623. The Merchant (0.40), the Bountiful (0.90 from 24 month ends) and the Generous (0.50 from 24, High at most a tenth) keep their first bars. The scripted runs trade little (trade income 0.2-5.5% of the bills) and never set Low, so no bar a real player could fairly meet would let a run earn those two; a seeded fixture earns each (T6 allows it). The Bountiful's 0.90 already parts the runs: the capital run's 0.985 earns it, the 20-year runs' 0.64-0.69 do not. — Cost if wrong: the Merchant and the Generous are earned by no scripted run, so their bars are not measured against play.
1624. T6 NOT MET in one part, left for the controller: the late dangers run earns the Builder, not the Unconquered. No bars can give both the great-work run the Builder and the late dangers run the Unconquered: the great-work run lays 1,042 units a raid beaten and the late dangers run 1,324, so any bars that put the first's units above its raids (Builder bar over Unconquered bar under 1,042) do the same for the second (it would need over 1,324). The rest of T6 is met: great work the Builder, three titles across the runs (Builder, Unconquered, Bountiful), each title earned by a run or a fixture. A different measure (raids a year, or finished monuments) would be a rule change. — Cost if wrong: the late dangers run, which beats 9 raids, is remembered for its monuments.

1626. T3 NOT MET for the Unconquered, pinned as measured, left for the controller: on seed 5 (the player's habits) it loses raids 6-12, all of which the Steady beats, its treasury gone (-28,072) and the run not won. The capital run (first warning on day 410, clock + 200), the late run (10 raids, all beaten), the late dangers run (10, all beaten) and seed 10 (11, all beaten) are met. The cause is the earlier clock, not the cheaper pay: with pay at 1 it loses the same seven; with `sooner` at 15 or 0 none (and wins the great work on day 6,380, the Steady's). `sooner` at 30, 45, 60, 75 and 90 loses 4, 2, 1, 8 and 7. One data number meets it: `sooner` 100 -> 15 days (5% of the 300-day clock, the design's smallest weakness), which leaves the weakness barely felt. — Cost if wrong: the pin holds a number the next sim change will move.
