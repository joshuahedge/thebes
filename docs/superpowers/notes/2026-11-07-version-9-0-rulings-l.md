# Version 9.0 "Dynasty": rulings 1585-1599 (Track L, the ruler list and rivals)

The list is src/ui/v90/rulers.js (the sheet and the title card's panel, the row, Play this map) and src/ui/v90/sideBySide.js; the map square is src/save/records.js `mapSquareOf`, `decodeMapSquare` and src/ui/share.js `drawMapString`, `mapSquareColour`; the backup is src/save/exportImport.js (`readRecordsFile`, `bringSummary`, `pickTextFile`) and src/ui/v90/rulerOptions.js (Options > Saves); the install ask is src/save/installFlow.js `installAskDue` with boot.js `noteFirstPass`; rivals are src/ui/share.js (`&name=`, `&heir=`), src/ui/scoreUi.js `titleDecor`, src/ui/v90/rivalToast.js and src/ui/v90/passSheet.js `passSheetExtras`.

1585. The ruler list's "replay" is Play this map: a new city on the same seed, level, layout and size, through New city's question (the game's card over a paused game; the title's card with its replace panel). — Cost if wrong: no time-lapse; a later release can add yearly snapshots.
1586. Bring rulers from a file merges rulers and rivals only (and, by the records' own rule, the dynasty's name when the device has none); a file's city rows, stamps and world are never read into the device, so cities stay un-importable (ruling 1146). Its question says "Adds N rulers and M rivals" (rulers by id and rivals by name and map that the device lacks) before Merge, or "Nothing new". — Cost if wrong: a player expects their city back from the file.
1587. The install ask comes once, at the first start of a city after a ruler is kept, on a device that can install: one toast with Install, and the list's top line while it is due; storage is asked to persist again then; the device remembers it was asked (`thebes.installAsk`), installed or not. The iOS guide adds the export-then-bring line. — Cost if wrong: a Safari player loses rulers in the first week, or a player who dismissed the toast is not asked again (the list's top line stays).
1588. A rival link adds `&name=` and `&heir=` outside the check and stays `t2`; both or neither (no name, no extras); older games ignore them. — Cost if wrong: a name can be edited in the link (friends' honour, as the score).
1589. A rival is kept per map; the same name on the same map replaces the older row; at most 50, never one on the map being played. A link opened is kept each time the title card shows it, and your own link is not special-cased. — Cost if wrong: a friend with two names counts twice; opening your own link makes you your own rival.
1590. At a new split, the newest rival on the map is compared in a toast, never in the lesson. — Cost if wrong: a player with many rivals sees one.
1591. The map square is 13 cell codes (the eight grounds, a rock belt's rock, a road, a plot, a built-up house, another building): a cell takes the tallest thing in its block of tiles (a building over a house over a plot over a road), else the ground of the block's middle tile. A road under a building, and the ground a small thing covers, are not drawn. — Cost if wrong: a small town on a big map reads as slightly busier than it was.
1592. The side by side is one component for the Pass sheet and an opened row: two scores with each side's heir, the five parts as paired bars with a number and the side's name beside each; a part a score v1 rival's link does not carry reads "not scored". `passSheetExtras` takes the rival from `ctx.rival`, else the records in `ctx.records` or `ctx.hooks.records`, and the score from `ctx.score` or the city measured now. — Cost if wrong: Track D's sheet passes the records some other way and the side by side is silently absent.
1593. The ruler name is one labelled field in Options > Saves, kept when the player leaves it or presses Enter, cleaned to letters, digits, spaces and `'-.` up to 16, and refused with the reason when nothing is left (it stays as it was, so the name cannot be cleared). — Cost if wrong: a player cannot go back to the default name once chosen.
1594. The ruler list is one panel at a time: a sheet in the game (the menu's Rulers), the card's panel with Back on the title. The title's records box shows its Rulers button only while a ruler is kept; neither the list, Bring rulers nor the name field exists in the lesson. — Cost if wrong: a player with no ruler finds no empty list to read about.
1595. A row's name is the name, its regnal number in Roman numerals (the first of a name is I) and the title: "Ramesses I the Steady". — Cost if wrong: the first reign of a name reads oddly with an "I".
1596. The rival toast and the row's words count whole game months (day / 30), as `splitMonths` does for the link; a rival whose link had not reached the split says "has not got there yet". — Cost if wrong: a rival and a player a few days apart in the same month read "level".
1597. Rows are read from `records.rulers()` whatever wrote them, so a ruler Track D writes at the Pass, one brought from a file and one a test seeds all list the same. — Cost if wrong: none known.
1598. A ruler row without a readable map string shows a blank square (sand), not a gap. — Cost if wrong: an old or hand-edited file's rows look unfinished.
1599. Your own link (its name is the dynasty's) is never kept as a rival, and the install ask's flag is written only when its toast is shown or the device is installed (Chrome allows install only after its prompt event). — Cost if wrong: a friend who shares your name is not kept as a rival.
