# Version 9.2, Track D (the dynasty's moment): rulings 1815-1824

1815. The sealed-ruler card is a custom sheet kind `passSealed` between the Pass sheet and the heir card; the Pass button opens it, nothing is sealed or written until the heir card's Start, and its Back is the Pass sheet. If wrong: one extra tap before the heir's city; the sheet kind is one line to drop.
1816. An heir's city (a ruler kept on the device, or a trait to play) starts with no beginner's guide, and the heir card's layout starts on the sealed city's `mapVariant` (Surprise me when that layout is not offered, e.g. oasis), set once per Pass so the player's pick stays. If wrong: a returning player who wants the guide has Resume guide in How to play.
1817. The heir's first screen has one voice: Ipi's bubble says "Heir of the Builder. Monuments rise 15% faster; taxes 5% lower." (9 s); the "is remembered as" toast is gone (the sealed card already said it) and the install ask is held to the first month end of an heir's own start (`startHeir` passes `heirStart`). If wrong: the ask lands a month later than before; the Rulers list still asks at any time. Without an interface root the line stays the old caption.
1818. A Rulers row is headed by the cartouche on its own line (name and number on one line, ellipsis not wrap; the title under it), rank, years, score and map square under it. The cartouche is drawn once (`src/ui/v92/cartouche.js`) and used whole on the sealed card. A name line of 16 characters or more is `long`: on the full card its facts go under it, not beside it (5.4). If wrong: a 15-character line may still be tight at 150%; LONG_NAME is one number.
1819. The title's record line is "Best reign: 200, Bronze" (the medal is the best's own version's, `records.bests` keeps it per version; "older scoring" still says so). The seed, level and size are the Rulers list's (an opened row) and the line's tooltip. If wrong: a player with several bests cannot tell them apart by line; the tooltip is the only place.
1820. The install ask appears once, at the top of the Rulers list (as the list already drew it); the heir's toast is held, not removed, so a device that can install is still asked once in its life.
1821 to 1824. Not used.
