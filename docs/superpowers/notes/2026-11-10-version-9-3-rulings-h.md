# Version 9.3, Track H (homes): rulings 1890-1899

- **1890. housing.js exports `HOUSE_LOOKS` unexpanded, and registry.js puts it through `withLooks(..., { variants: 3 })`, as Track B does for its tables.** A drawing file cannot call withLooks as it loads (registry.js imports it first: a TDZ error on `EXPANDED`); an earlier draft moved withLooks to a new file, dropped for B's fix. Cost if wrong: none; one place expands tables.
- **1891. Homes are `house.t{1..9}.v{0..2}.l{0..3}`; `house.lot` stays one slot; the plain `house.t<n>` stays as an alias of its `.v0.l0`** for the card thumbnail (ui/thumbs.js) and older callers. Cost if wrong: a card shows the Village hut; six older tests that asked slotFor for `house.t<n>` now expect `.v0.l0`.
- **1892. Variants differ in massing, not detail (Josh's note).** v0 the tier's own block (single block, or block and annexe; the big homes' wing), v1 stepped (tall back block and low front block with an outside stair; the big homes' tower), v2 a courtyard (a low block, walled court, palm and wind-catcher; the big homes' set-back top storey). The tier's roof tell stays on every variant. Cost if wrong: only the drawings change.
- **1893. The far drawing is `house.t{n}.l{look}.far`, chosen by `slotFor(b, world, { far })`; the renderer passes `far` when the camera is at 0.6 or under (`FAR_ZOOM`).** It is the v0 shape with no clutter (no jars, linen, palms, awnings, pergola, rug, bed, statue). Cost if wrong: one constant.
- **1894. One height and one shadow set per tier, whatever the variant or look.** Heights are the tallest ink of any drawing (+2); the older code that reads `ART[slotFor(b)].height` (pick, markers) therefore never changes with a variant. Cost if wrong: a ground shadow a few px off on a variant that is not v0.
- **1895. A City or Capital big home's walls are 0.7 px taller than a Village one's**, so no look is shorter than the Village look (its roof slab stands 0.7 higher). Cost if wrong: a sub-pixel height.
- **1896. The sick cloth reads the door from the drawing.** `homeDoor(tier, variant)` runs the drawing against a canvas that takes no ink and reports its first main door; `illness.js` `clothFor` uses it in place of its fixed table. Cost if wrong: the cloth hangs where the door was; the table stays as the fallback.
- **1897. The 2x2 homes keep their courtyard front-left and the pool at `[0.32, 1.24, 0.6, 0.3]` in all three variants**, so the ambient pool glint (render/ambient.js) still sits on the water. Cost if wrong: the glint floats; change `BIG_POOL` and ambient together.
- **1898. Today's drawings stay as `HOUSE_TODAY` (and H1..H9, BIG, PERGOLA, ...).** The look sheet's "today" column and the older pixel tests use them; the game does not. Cost if wrong: dead code to delete in a later pass.
- **1899. Colour stays in every look:** painted doors (three by variant), awnings, canopies and the tier's roof tells keep their colours in the City and the Capital; the look changes walls, roofs, trims and bands. Cost if wrong: none to the sim.
