## Lessons from writing and executing the 1c plan (apply here)
- A code block split across two appends needs its closing fence before the "Continue ..." line; two unclosed fences in 1c inverted every later fence and merged two task briefs.
- Appends of about 120 lines per tool call worked; keep them under 130. Write prose files with the Write tool, not a heredoc, when they contain many quotes and backticks.
- Headless Edge reports prefers-reduced-motion, so tests that expect a camera tween set the setting off first.
- Every 1c task needed a fix round; the reviewers earn their cost. Keep the task reviewer's named risks concrete.
- The commit trailer stays `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (Josh's rule); amend any implementer commit that uses its own model's line.
