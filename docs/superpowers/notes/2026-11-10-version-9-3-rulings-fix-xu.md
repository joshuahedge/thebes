# 9.3 fix wave, group xu (the decree's interface and records): rulings 1995-2004

1995. The week helpers (`isWeekKey`, `weeklySeed`, `decreeMapOf`, `decreesOfWeek`, and the rest) live in `src/data/week.js`; `src/ui/week.js` re-exports them. `records.js`, `boot.js` and `rulers.js` import the data module. Cost if wrong: none at runtime; a stale import path in a test of the old path still works.
1996. The top bar's date holds the last day of year 6 once the decree has ended (the HUD reads `endDay - 1`), so it agrees with the chip's "Year 6 of 6". The sim's day is untouched. Cost if wrong: a player may expect the bar to run on; nothing else reads this date.
1997. A decree run has no chapter goals: the goals strip, the goals sheet's chain count, the City page's goals and the nudge read none (a local `openGoals` wrapper in goalsList.js, createUI.js and sheets.js returns an empty list when `world.decree`). The sim's goals still exist and are not touched. Cost if wrong: a decree run's goal-completion captions could still fire from the sim.
1998. In a decree run the top bar's score chip and the City page's score section read `decreeScore` (out of 600, with the bonus part) and count to `decreeMedals`; the five parts and their reasons stay `scoreOf`'s. Cost if wrong: the chip's number differs from the city score a player saw before; it is the same number the end card shows.
1999. The decree chip puts a dot between the year and the mark. The twist lines on the title card are `.small`, left-aligned, the mark its only bold line; the card's go button is a plain button, so Play stays the title's one primary. Cost if wrong: looks only.
2000. A finished run is noted when it arrives (the seam's `noteEnd`, on `decree_end`), not when the card draws; boot's `leaveDecree` and `again` note an ended, un-noted run as a second guard. The row's `title` is `titleOf(world).id` (S2). Cost if wrong: a second note is harmless, since `world.decree.noted` gates it.
2001. After the end, `decree_ended` reads "The decree has ended", and Play, the speed buttons and the keys open the end card (the seam wraps `speedControl.set`). While it is over, the alerts banner, the tip and the scribe's line are hidden. Cost if wrong: a player who wants the debt alert after the end does not see it.
2002. The title's Rulers button counts decree rows with rulers (the label's number is the sum). The end card's side-by-side lists six parts (`sideBySide` takes `ids` and `names`). A pair week's end card shows each decree's own part under the bonus. "Week N" keeps its number with a no-break space on the card and sheet. Cost if wrong: the Rulers number counts two kinds of row.
2003. Under Low Nile the granary drawing reads `capacityOf(world, 'granary')` (`granaryStage(b, world)`; registry's slotFor passes the world). Cost if wrong: a granary shows one step lower than it did; no sim change.
2004. The elephants' twist line reads "War elephants may come from the 2nd raid" (the sim brings them in half the raids). The bonus line lowercases only its first letter, so tier names keep their capital.

Ruling 1970's text says "classic layout": stale. A decree rival carries the week's real map (`decreeMapOf(week)`: its seed and layout, with Sea Peoples never on the Great oasis).
