## Lessons from writing and executing the 1b plan (apply to 1c)
- Pixel tests must be reasoned in device px: test canvases are translated and `makeDraw` scales by 2. Several 1b test coordinates fell off-canvas.
- Each plan append to the file must stay under about 100 lines per tool call or the call is cut off.
- Registry `height` = max z-top above the ground plane; `bounds` must contain all ink (`tests/render/artBounds.test.js`).
- Loop tests must respect `MAX_FRAME_SECONDS` (0.25 s per frame).
- A visible-range filter on the rotated-rectangle bounding box is too coarse; sort by distance to the view centre.
