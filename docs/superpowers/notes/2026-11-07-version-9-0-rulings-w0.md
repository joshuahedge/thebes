# Version 9.0 "Dynasty": rulings 1560-1564 (wave 0, the shared pieces)

The save is src/data/v90.js (`V90_TALLY`, `HEIRS`), src/sim/world.js (`createWorld`'s `heir`), src/save/serialize.js and src/save/migrate.js `v11ToV12`; the records src/save/records.js (version 2); the seams src/sim/dynasty.js, src/ui/v90/passSheet.js `passSheetExtras`, src/ui/v90/rivalToast.js `onSplit` (called from src/ui/createUI.js), the game menu's two rows in src/ui/menu.js, src/render/v90/effects.js `effectsV90` (called from src/render/renderer.js), css/v90.css and the three headers at the end of src/ui/text.js. Tests: tests/v90/w0/.

1560. World version 12. `world.heir` is required and one of `HEIRS` (builder, unconquered, bountiful, merchant, generous, steady): `createWorld({ heir })` takes it, anything else and a v11 city start the Steady. The four month-end counts (`V90_TALLY`: townMonths, fedMonths, tradeGold, billsPaid) live in `world.tally` beside 8.4's, at 0 in a new and a migrated city. A seal's `passed` and `title` are optional, absent on every older seal. A v11 city loaded and played a year matches the same city played without the load. `countDynastyMonth` runs once at each month's end after `recordGoodsMonth` (so after `monthlyEconomy`, the milestone's update and the goods' month record: `stats.lastMonth.tradeIncome` is whole) and before the month-end row. — Cost if wrong: one more migration to keep.
1561. Records version 2: `rulers` never capped; `rivals` at most 50, the oldest added going first and never one on the map being played (`addRival`'s `playing`; a merge has no map being played); `dynasty` `{ name, heir }`, name '' until the first Pass and heir 'steady' on a new device. A version 1 blob reads with the three empty, and `normalizeRecords` drops what it cannot read. A name (ruler, dynasty, rival) keeps letters and digits of any script, spaces and `'-.`, at most 16. A rival's id is its name and map's key, so the same name on the same map replaces the older (the newer `added` wins in a merge). `mergeRecords` merges rulers by id (the device's row kept); the device's dynasty stays, taking the file's name when it has none and the file's heir when the file holds the newest ruler. — Cost if wrong: a big dynasty's list grows `localStorage` by about 1.3 KB a ruler.
1562. The records' new shape lands in wave 0, fully tested and called by nothing: `addRuler(world, seal, title, now)` (id `cityId:seal.day`, so a second call replaces it; name the dynasty's, else "Ramesses"; `n` 1 + the rulers before it of that name; the map's newest rival copied into `rival` as it stands; `map` from `mapSquareOf(world)`, '' until Track L writes the encoder), `rulers()` newest first, `dynasty()`, `setDynasty(patch)` (a name that cleans to nothing or an heir not in `HEIRS` leaves that one as it was), `addRival(link, now, { playing })` (the link is `parseShareLink`'s reading with `name` and `heir` as ids; its score the link's parts times the level's factor, as `sharedTotal`), `rivalsFor(seed, difficulty, variant, size)` newest first. Ruler and rival rows always carry `mapSize`. — Cost if wrong: none.
1563. The seams, each a stub with 8.4's behaviour: `heirFactor(world, lever)` 1, `titleOf(world)` `{ id: 'steady', fit: 0 }`, `countDynastyMonth(world)` nothing; `passSheetExtras(body, world, ctx)` draws nothing; `onSplit(world, id, ctx)` says nothing, called by the interface once for each split recorded after it opened (checked when each batch of sim events arrives; a loaded city's splits never call it); the game menu's Pass the throne after New city (while `hooks.passThrone` exists and `hooks.canPassThrone()`, when given, says yes) and Rulers after it (while `hooks.rulers` exists), both absent in the lesson; `effectsV90(g, view, world, { ...opts, range, cam })` once a frame after the effects pass and before the overlays; css/v90.css linked last; the text.js sections for D, L and V in merge order, with `V90_D_TEXT.menuPass` and `V90_L_TEXT.menuRulers`. — Cost if wrong: none.
1564. The lesson's world is always the Steady (`lessonWorld` passes `heir: 'steady'`), whatever the device's dynasty holds; New city takes `records.dynasty().heir`, and the development sample and stress cities stay the Steady so the shots and budgets never move with the device. — Cost if wrong: none.
