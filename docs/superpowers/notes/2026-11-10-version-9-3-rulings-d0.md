# Version 9.3 rulings, Track D0 (1950-1954)

- **1950.** The plan's week and rotation test values (ISO weeks, week indexes, decrees of weeks 46 to 51) were checked against the real calendar and hold as written. Cost if wrong: the week's decree would differ from the plan's table.
- **1951.** `weekIndex` counts from 2026-W47 and `isPairWeek` is every fourth index (3 mod 4), as planned; both work before the epoch. Cost if wrong: pair weeks shift by a week.
- **1952.** `ruleFactor` is `heirFactor` times the decrees' factors; every other rule function is 1 (or the base given) with no decree. Cost if wrong: the main game moves, and the golden test fails.
- **1953.** `createWorld({ decree })` drops unknown ids, ignores a decree with no valid id or no string week, and forces the Steady heir and Normal. `validateWorld` already accepts an extra top-level key, so no change to `serialize.js`; a test packs and unpacks a decree world. Cost if wrong: a decree save would not load.
- **1954.** The golden fingerprint (72 month ends) reuses the v92 capital6 run: `capital6.js` now passes an `onMonth` that records `monthRow(w)` (so its events array is `[]` rather than null; the sim ignores it) and exports `capital6Months()`. "raids" is `w.raid.index` (raids warned so far); the tally keeps every `TALLY_KEYS` entry of this commit (89 keys), a literal list in `tests/v93/helpers/golden.js`. Recorded by a throwaway test, checked in as `tests/v93/d0/golden.json`; proven to bite by raising the grain farm's perMonth from 30 to 31 (fails at month 2), then reverted. Cost if wrong: a sim change outside the score, gold, people, raids and tally would slip past.
