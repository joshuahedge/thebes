# Version 9.3, Track R rulings (1955-1964)

One line each, with its cost if wrong.

- **1955 (R.1, R.2 pay):** `ruleFactor` replaces `heirFactor` in the six sim files. A unit's pay is `ruleUnitPay` per kind inside `soldiersPayFull` (spoils.js), summed then rounded once, so `soldiersPayOf` and the spoils saving agree. Cost if wrong: archers' pay is off by a rounding gold a month.
- **1956 (R.3):** no single capacity function existed, so `capacityOf(world, type)` in rules.js is the one, and `hasSpace`, `roomOf`, the court's, trade's and elephants' room, alerts, the drought count and `setFetch` read it. `hasSpace` and `roomOf` gain an optional `world`. Cost if wrong: a place that still reads `BUILDINGS.x.capacity` shows or uses a granary's old 600 (the `src/ui` ones are Track U's).
- **1957 (R.6):** the flood step moves the drawn level along FLOOD_LEVELS and clamps; a drought's forced Low is returned before the step. Cost if wrong: Low Nile is a step weaker even in a drought year (already Low, so no change).
- **1958 (R.4):** the first warning is `round(firstWarnAfter x raidGap) - sooner`; a later one draws between `round(laterMin x raidGap)` and `round(laterMax x raidGap)`. The band size is multiplied only for raid index 1 on (the first raid keeps `firstSize`), rounded and capped at `RAIDS.maxSize`, after favour and wealth. The boat share replaces the boat row's `base` and `max` (0.25) in the mix. Cost if wrong: Sea Peoples' first raid is as it was.
- **1959:** elephants come from `ruleElephantsFrom(world, 4)`, read in `elephantRaid` only (`enemyMayCome` is unchanged). Cost if wrong: none for other kinds.
- **1960 (R.5):** `sickSpread` and `fireStart` multiply the data chances at their one call each; the firehouse reach is `ruleReach` in `fireCoverage` and `fireCause`. Cost if wrong: Track U's placement count and the danger sheet still use 8 until they switch.
- **1961 (R.5 court):** `courtAsk` multiplies the ask of every ordinary request (soldiers clamped as before) and `courtReward` multiplies the reward on top, so a Levy request pays about four times a plain one's gold. The guided letter is untouched. Cost if wrong: the Levy pays 2x rather than 4x (one factor in `withReward`).
- **1962 (R.7, R.9):** `typeReason` and `previewWallTiles` refuse `ruleForbids` types with `'decree'`. There is no single command entry, so 28 command functions begin with `if (decreeEnded(world)) return endedFail()` (`{ ok: false, reason: 'decree_ended' }`), `tickDay` returns at once, and `runMonth` sets `ended` and speed 0 at the month end on or after `endDay`. Cost if wrong: a command added later without the line works after the end (Track U also locks the interface).
- **1963 (R.8):** `wellMonths` and `fireSafeMonths` are in `newTally` but not in `TALLY_KEYS`, so an old save loads and reads 0. They count from Town in `countDynastyMonth`; a month is fire safe when no `danger.burnDays` entry is within the last 30 days. Cost if wrong: both bars would want a different start month.
- **1964 (R.10):** the medal is judged on the sum of the six parts (a decree run is Normal, factor 1). `decreeMedals(world)` is exported for tests and for Track U. A pair outside `DECREE_PAIRS` has no medal. Cost if wrong: a Hard decree run would need a factor (decree runs are forced to Normal).
